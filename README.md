# Flat Earth Cosmos

Интерактивная Android-лаборатория для визуального исследования альтернативной модели плоской Земли, небесного купола и локальной небесной механики.

> Это экспериментальная визуализация и программная модель гипотез. Она не является утверждением о физическом устройстве мира. Все нестандартные параметры, проекции и оптические допущения отображаются явно.

## Возможности

- Внешний 3D-вид: диск, ледяная стена, купол, Солнце, Луна, орбиты и звёздное поле.
- Вид наблюдателя изнутри с перспективной проекцией, горизонтом и наземным слоем.
- AR-компас: направление взгляда синхронизируется с rotation vector сенсором Android.
- 2D-карта с проекциями AE, stereographic и orthographic.
- Масштабирование 2D-карты, подписи материков и быстрый переход к текущей геопозиции.
- Жесты двумя пальцами: масштабирование и панорамирование карты без уменьшения окна просмотра.
- Солнце с сезонным движением, суточной скоростью и зоной освещения.
- Луна с независимым движением, фазами и процедурной текстурой.
- Именованные созвездия и дополнительное процедурное звёздное поле.
- Разделение геометрического и наблюдаемого положения объектов.
- Численная атмосферная оптика с рефракцией и оптической толщиной пути.
- Скрываемый HUD, телеметрия, формулы и справочник исследователя.
- CC0 ambient-трек с регулировкой громкости и остановкой при сворачивании приложения.

## Быстрый старт

1. Скачайте APK из [последнего релиза](https://github.com/Liberatorian/Flat-Earth-Rus/releases/latest).
2. Установите APK на Android-устройство. Для debug-сборки может потребоваться разрешить установку из выбранного источника.
3. Откройте `Вид с Земли`, выберите город или пользовательские координаты.
4. Нажмите `AR компас`, чтобы управлять направлением телефона.

## Управление

- `3D Купол`: внешний осмотр, перетаскивание вращает камеру.
- `Вид с Земли`: свайп меняет азимут и высоту взгляда, pinch меняет поле зрения.
- `Карта 2D`: нажатие по диску задаёт точку наблюдателя, кнопки масштаба помогают рассмотреть материки.
- На 2D-карте `N` сверху, `E` справа, `W` слева; это стандартная северная азимутальная ориентация.
- `Точка наблюдения`: кнопка геопозиции подставляет координаты устройства после выдачи разрешения Android.
- `♫`: фоновый процедурный звук с отдельным переключателем и регулировкой громкости; при сворачивании приложения звук останавливается.
- При запуске приложение показывает фактическое UTC-время и синхронизирует его с реальными часами.
- В панели времени отображается локальное время устройства с обозначением часового пояса; UTC остаётся доступным в телеметрии.
- При первом запуске приложение запрашивает разрешение геопозиции и подставляет актуальные координаты устройства; при отказе доступны город и ручной ввод.
- `Слои`: сетки, световые лучи, звёзды, допущения и выбор проекции.
- `Формулы`: основные преобразования и уравнения модели.
- `Справочник`: размеры, параметры, проверяемые следствия и ограничения.

## Расчётная модель

Базовые координаты диска:

```text
r = R * (90° - latitude) / 180°
x = r * sin(longitude)
y = -r * cos(longitude)
```

В проекте отдельно хранятся:

- геометрическое положение объекта в выбранной модели;
- наблюдаемое положение после атмосферного пути, рефракции и перспективной проекции.

Основные демонстрационные параметры: радиус диска `20 000 км`, высота Солнца `4 800 км`, высота Луны `4 750 км`, физическая высота ледяной стены `75 м`, профиль купола `0–10 500 км`.

Звёздное вращение рассчитывается по сидерическому времени: около `15.041°/час`, полный оборот за `23 ч 56 мин 4 с`.

## Научная честность

Приложение предназначено для сравнения геометрических гипотез и визуальных следствий. Оно не заменяет астрономические измерения и не скрывает места, где используются:

- азимутальные и экспериментальные проекции;
- параметрическая подгонка траекторий;
- локальное пятно освещения;
- нестандартный профиль купола;
- экспериментальная рефракция и атмосферные коэффициенты;
- визуальное масштабирование.

## Сборка из исходников

Требования: Android SDK 36, JDK 17.

```bash
ANDROID_HOME=/path/to/android-sdk \
ANDROID_SDK_ROOT=/path/to/android-sdk \
bash ./gradlew :app:testDebugUnitTest :app:assembleDebug
```

APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`.

## Лицензирование и ресурсы

Визуальные ресурсы модели генерируются кодом и не требуют внешних изображений или аудиозаписей. Проект распространяется как открытый исходный код для образовательного и экспериментального использования. Перед коммерческим распространением проверьте лицензионные условия зависимостей Android/Gradle.
